说明
· .mo 是 gettext 编译后的二进制文件，反编译即还原出可编辑的 .po 源码（含 msgctxt、复数形式与转义）
· 自动识别大端 / 小端序，并按 .mo 头部声明的字符集解码（缺省 UTF-8）
· PO → MO 会跳过 #~ 废弃条目，默认排除 fuzzy 条目，与 msgfmt 的行为一致
· 生成的 .mo 不含哈希表，字符串表按字节序排序，可被 gettext / PHP / Python 正常读取
· 编辑 / 查看：上传 .mo 或 .po 后可直接浏览全部条目，点击任意一行修改译文（改动即时写入，Ctrl+Enter 完成），编辑完可另存为 .po 或 .mo
· 复数条目会按文件头 Plural-Forms 里的 nplurals 自动展开对应数量的译文框；被标为 fuzzy 的条目默认不会写入 .mo
